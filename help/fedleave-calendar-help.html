FedLeave Calendar Help

FedLeave Calendar is a graphical month view for the fedleave command-line backend.

Calendar Layout

The main window shows month navigation, a calendar grid, pay periods touching the displayed month, and balances as of today.

Day Cells

Each day cell shows the day number, nonzero leave entries, holidays, pay days, and pay-period endings. Zero values are intentionally not shown.

Leave Abbreviations

A = Annual Leave, S = Sick Leave, Cr = Credit Hours, Comp = Comp Time, OT = Overtime, TC = Travel Comp, RA = Restored Annual.

Sign Convention

Positive values are earned or worked. Negative values are used or deducted.

Day Editing

Click a day to edit supplied leave categories authoritatively. Saving calls the fedleave backend and reloads the month from backend JSON.

Preferences

Preferences can set a backend executable, optional data directory, first day of week, display toggles, font size, print orientation, and PDF export folder.

Printing and PDF Export

Print preview, printer output, and PDF export render a report from backend month data. Reports do not show zero values.

Troubleshooting

If the backend cannot be found, open Preferences and set the fedleave executable path. The GUI does not fabricate data after backend failures.
